# Web 管理界面

AmritaBot WebUI 是 Amrita 原生的管理界面，用来查看运行状态、管理插件与会话配置。前端是 React SPA，后端复用 NoneBot 的 FastAPI 服务，因此不需要单独开端口。

## 访问

WebUI 与 Bot 共用同一服务端口，端口由环境变量 `PORT` 控制（NoneBot 默认 `8080`，Amrita 示例 `.env` 使用 `11451`）。例如使用默认端口时，WebUI 地址为：`http://localhost:8080`

登录页会直接显示当前 AmritaBot 版本，排查问题时可以先确认这里与 `pyproject.toml` / PyPI 上的版本是否一致。

## 账号与密码

WebUI 使用独立的账号密码登录，通过环境变量配置：

```dotenv
WEBUI_USER_NAME=admin        # 登录用户名（默认 admin）
WEBUI_PASSWORD=your_password # 登录密码
```

> **重要**：默认密码为 `admin123`。**只要密码仍为默认值（即未在 `.env` 中设置 `WEBUI_PASSWORD`），WebUI 即处于锁定状态**：所有页面与 API 请求都会被拒绝并返回 423（`requires_password_change`），提示您先在 `.env` 中设置 `WEBUI_PASSWORD` 后重启 Amrita。**设置一个非默认密码并重启后，WebUI 才会解除锁定。**

## 安全机制

- **默认密码锁定**：未修改默认密码（`admin123`）时 WebUI 整体锁定，杜绝开箱即用的弱口令暴露
- **登录失败锁定**：连续登录失败 **20 次**后触发安全锁定，拒绝所有登录请求（重启 Amrita 后解除）
- **登录限速**：同一 IP 每秒最多尝试 10 次登录
- **会话过期**：登录 Token 有效期 30 分钟，过期需重新登录；快过期时已登录会话会自动续期
- **密码加密存储**：密码以 bcrypt 哈希保存，不存明文
- **HttpOnly Cookie**：认证信息存放于 HttpOnly Cookie（`SameSite=Lax`），前端脚本无法读取

即便如此，仍请不要把 WebUI 直接暴露到公网。

## 插件管理

插件管理分为「已安装」与「插件商店」两个标签页。1.11 起，商店与安装流程都在 WebUI 内完成，不需要再手改 `pyproject.toml`。

### 已安装

列表把插件归为六种状态：运行中、已启用待重启、已禁用待重启、未加载、依赖项、内置插件。内置插件与 `nonebot-plugin-amrita` 这类被 Amrita 直接 `require` 的依赖不允许在页面里禁用，按钮会给出原因。

> 📷 截图占位：已安装插件（待补）

### 插件商店

商店聚合两个来源：

- **NoneBot 商店**：`https://registry.nonebot.dev/plugins.json`，由后端拉取并缓存。
- **Amrita 官方插件**：文档站的 `official-plugins.json` 清单，只存插件身份；版本、描述与依赖约束在运行时从 PyPI 解析。

列表支持按来源、官方标记、标签、当前适配器筛选，并默认隐藏与当前环境不兼容的条目。每条会标出 PyPI 版本、安装状态与不兼容原因。

安装、卸载、启用、禁用都是异步任务，页面会显示任务进度与最终输出。安装完成后通常需要重启 Bot 才会加载新插件；已安装但未启用的插件会停留在「已启用待重启」状态。

::: tip 版本来源

官方清单不写死版本号，避免清单过期后把用户锁在旧版本。列表里的版本来自 PyPI，可能带有缓存标记；需要最新结果时点一次刷新。

:::

## 聊天管理

### 模型预设

模型预设页面用于维护 `config/chat/models/` 下的预设。新建或编辑时，协议字段是从 `/api/chat/models/adapters` 拉取的已注册适配器下拉框，旁边会提示当前协议由哪个适配器处理，不再需要手输协议名。

> 📷 截图占位：模型预设（待补）

### 提示词预设

群聊与私聊模板分开管理。`/prompt` 指令切换模板属于全局配置写入，1.12 起要求超级管理员（`superusers` 或 `lp.admin`），普通群管理员不能再改。

### MCP 服务器

列表由运行时状态生成，显示运行时 ID、脚本地址、连接状态与工具数量。单个服务连接失败不会影响其他服务，失败原因会直接显示在行内。

### 技能管理

技能页面提供总开关、执行策略和工具注册模式：

- **回显技能目录**：控制技能返回内容是否带本机目录前缀，远程沙箱场景建议关闭。
- **允许执行技能脚本**：关闭后不再注入 `scripts/` 下的脚本工具，技能只返回 `SKILL.md` 正文。
- **工具注册模式**：`progressive` 统一注册 `skill_open` / `skill_read`；`invoke` 为每个技能注册一个工具，兼容旧行为。
- **全部启用**：写入 `all_skills = true`。关掉最后一个技能即「一个都不启用」，空 `selected` 不再表示全部启用。
